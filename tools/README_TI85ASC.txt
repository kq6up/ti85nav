ti85asc - modern Unix/Linux ASCII85P-compatible TI-85 converter
================================================================

Build:
    make
or:
    cc -std=c99 -O2 -Wall -Wextra -Werror -o ti85asc ti85asc.c

Commands:
    ./ti85asc lint SOURCE.ASC
    ./ti85asc pack SOURCE.ASC OUTPUT.85P
    ./ti85asc unpack PROGRAM.85P > SOURCE.bas
    ./ti85asc check PROGRAM.85P

Strict validation is the default. Unknown ASCII85P-style backslash escapes,
malformed wrappers, invalid NAME fields, NUL bytes, and unsupported source
bytes cause conversion to stop with filename and line-number diagnostics.

For old permissive behavior:
    ./ti85asc pack --lenient SOURCE.ASC OUTPUT.85P

Compatibility implemented and verified for the escape forms used by the
current celestial-navigation programs:
    \->\      store arrow
    \>=\      greater-than-or-equal
    \sin^-1\  inverse sine
    \cos^-1\  inverse cosine
    \tan^-1\  inverse tangent
    \pi\      pi character

The converter uses the TI-85 native plain-text program representation rather
than tokenizing BASIC keywords. This matches the format generated by TI's
ASCII85P.EXE for these programs.

Regression result:
    Packing the authoritative SIGHT V8 ASCII source with this converter
    produces a byte-for-byte identical SIGHT.85P to the binary generated by
    the original ASCII85P.EXE (SHA-256 identical).

The included prebuilt ti85asc-linux-x86_64 is provided for convenience.
Building from source is preferred on other architectures or distributions.
